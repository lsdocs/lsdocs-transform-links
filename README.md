# lsdocs-transform-links

Part of [lsdocs](https://github.com/lsdocs), a static-site generator whose
parsers, transformers and renderers are plugins.

`crates/transform-links` (`lsdocs-transform-links`, builtin
`transform-links`): checks and resolves links between pages, reporting
broken ones as warnings.

Its settings and behavior are described in the lsdocs documentation
(https://lsdocs.github.io, "transform-links").
